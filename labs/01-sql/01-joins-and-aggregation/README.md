# Lab 01-sql / 01-joins-and-aggregation

## Why this lab

Stated starting point: comfortable with simple single-table SQL, but joins
and aggregation so far have mostly been generated by JPA/Hibernate rather
than hand-written. This lab is entirely about closing that gap — no ORM,
just SQL against a real Postgres instance.

## Scenario

A small synthetic construction-material store: customers, products, orders,
and order line items. See [setup/schema.sql](setup/schema.sql) for the exact
structure — read the DDL yourself before starting rather than waiting for a
description of it.

## Setup

```bash
cd docker
docker compose up -d
docker exec -i dbeng-lab-postgres psql -U lab -d dbeng_lab < ../labs/01-sql/01-joins-and-aggregation/setup/schema.sql
docker exec -i dbeng-lab-postgres psql -U lab -d dbeng_lab < ../labs/01-sql/01-joins-and-aggregation/setup/seed.sql
```

(Already loaded once in this session to confirm the schema/seed are valid —
re-running the above is safe if you want a clean instance; `CREATE TABLE`
will just fail loudly if the tables already exist, which is fine.)

Connect however you like: `docker exec -it dbeng-lab-postgres psql -U lab -d dbeng_lab`, Adminer at http://localhost:8080, or any SQL client pointed at `localhost:5432`.
